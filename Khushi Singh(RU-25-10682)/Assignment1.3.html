Function of the <img> Tag in HTML

The <img> tag in HTML is used to display images on a webpage. It is an empty tag (it does not have a closing tag) and requires attributes to specify the image source and description.

Syntax:

    <img src="image_path" alt="description" width="value" height="value">

Explanation of Attributes:

  • src (Source): Specifies the URL or file path of the image to be displayed. Example: src="image.jpg"
  • alt (Alternate Text): Provides a text description of the image if it fails to load or for screen readers (important for accessibility). Example: alt="Beautiful Sunset Image"
  • width and height: Define the size of the image in pixels. Example: width="200" height="200"
