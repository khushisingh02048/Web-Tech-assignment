Use of Attributes in HTML

1. The href Attribute

The href attribute in the <a> tag defines the link destination.

Visit Google

2. The src and alt Attributes

The src attribute in the <img> tag specifies the image source file.
The alt attribute provides alternative text if the image cannot be displayed.

3. The title Attribute

The title attribute adds a tooltip when the mouse is placed over the text.

Hover over this text to see the tooltip!

4. The style Attribute

The style attribute is used to apply inline CSS styling to elements.
