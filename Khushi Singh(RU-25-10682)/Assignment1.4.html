Difference Between <ol> and <ul> Tags in HTML

HTML provides two main types of lists to organize content:

  • <ol> (Ordered List) – Displays items in a numbered list.
  • <ul> (Unordered List) – Displays items with bullet points.

1. Ordered List (<ol>)

Items in an ordered list are numbered automatically. It is used when the sequence or order matters.

  1. Wake up
  2. Brush Teeth
  3. Have Breakfast
  4. Go to School

2. Unordered List (<ul>)

Items in an unordered list are marked with bullet points. It is used when the order of items is not important.

  • Apple
  • Banana
  • Orange
  • Mango

Summary of Differences:

Feature <ol> (Ordered List) <ul> (Unordered List)
Symbol/Marker Numbers (1, 2, 3, ...) Bullets (•)
Order Importance Order matters Order does not matter
Use Case Steps in a process, ranked items Shopping list, features list, unordered items
